How it works
1
Subscribe to a channel with one curl command — use your TEX token, no extra sign-up needed.
2
Open your feed — events stream in as they happen, one JSON object per event.
3
Each general feed event includes a more field pointing to that channel's dedicated stream for deeper data.

Example — general feed output

event: price_update id: evt_1745123460_crypto-btc data: { "channel": "crypto-btc", "event": "price_update", "ts": "2026-04-21T09:01:00Z", "source": "CoinGecko /coins/bitcoin", "payload": { "symbol": "BTC", "price_usd": 94210.42, ... }, "more": "curl -N .../stream/crypto-btc -H \"Authorization: Bearer TOKEN\"" } event: earthquake_update id: evt_1745123465_earthquakes-live data: { "channel": "earthquakes-live", "payload": { "count": 42, "events": [...] }, "more": "curl -N .../stream/earthquakes-live -H \"Authorization: Bearer TOKEN\"" }
