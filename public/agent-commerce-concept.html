AgentPay Concept
Microtransactions for AI Agents

Pay-per-action commerce for autonomous AI agents

A concept marketplace where agents can discover services, agree to pricing through the Agent Commerce Protocol, and complete secure microtransactions through Stripe.

Machine-readable offers

Agents parse normalized price cards and service terms before purchasing.

Sub-cent pricing

Charge for one API call, one dataset row, or one workflow execution.

Trust + auditability

Each transaction includes capability scopes, receipts, and a replay-safe id.

How a transaction works

Step 1

Agent reads the merchant ACP endpoint for supported capabilities and pricing.

Step 2

Agent requests a quote and receives payment requirements and execution terms.

Step 3

Stripe completes authorization or capture, then returns transaction confirmation.

Step 4

Merchant fulfills the action and returns signed proof of completion to the agent.

Concept value proposition

For developers

Monetize APIs without forcing full subscriptions for low-volume use cases.

For agents

Programmatic checkout with explicit caps and predictable billing behavior.

For operators

Centralized fraud checks and settlement through Stripe infrastructure.
