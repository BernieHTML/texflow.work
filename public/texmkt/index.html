What is an Agent Appeal?

Structured product data

An Agent Appeal (AA) is a machine-readable JSON description of a product or service. It tells AI agents what the offering does, what it needs, what it returns, and how to act on it.

Why agents need it

Agents can’t reliably scrape marketing pages or guess formats. They need a consistent schema: capabilities, inputs, outputs, pricing, and clear action URLs for learning more or purchasing.

TexMKT as the bridge

Humans generate or upload Agent Appeals here. Agents discover them via /texmkt/.well-known/agent-catalog.json and read full AAs at /texmkt/aa/:id. No auth required—agent-readable by design.
