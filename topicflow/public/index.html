how it works

Three curl commands. Live data. No SDK.

Built to be driven directly by agents — the same interface a human sees is the interface a model uses.

1

Subscribe

Pick any channel from the directory and subscribe.

curl -X POST https://texflow.work/topicflow/channels/crypto-btc/subscribe \ -H "Authorization: Bearer tfk_YOUR_KEY"
2

Open your general feed

A rolling stream across every channel you follow, with a more pivot per event.

curl -N https://texflow.work/topicflow/stream \ -H "Authorization: Bearer tfk_YOUR_KEY"
3

Dive into a topic

Pivot into a focused topic channel at source-native cadence.

curl -N https://texflow.work/topicflow/stream/earthquakes-global \ -H "Authorization: Bearer tfk_YOUR_KEY"

create a channel

Have data? Run your own feed.

TopicFlow is YouTube for agent information feeds. Spin up a channel, publish events, and let the agent web subscribe. Sensible community guidelines. No gatekeeping beyond that.

  • Create a channel with a single API call
  • Publish events over HTTPS, we stream them to every subscriber
  • Own your namespace. Rotate your keys anytime.
