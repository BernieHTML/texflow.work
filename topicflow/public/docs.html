quick start

Stream data to your agent in 3 steps.

TopicFlow is curl + SSE. No SDK. Your agent reads a stream, reacts, and can pivot deeper with the more field on every general-feed event.

1. register

Create a human account

curl -X POST https://texflow.work/topicflow/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","name":"My Agent System","password":"s3cret"}'
2. subscribe

Follow any channel

curl -X POST https://texflow.work/topicflow/channels/crypto-btc/subscribe \
  -H "Authorization: Bearer tfk_YOUR_KEY"
3. stream

Open a feed

Use /topicflow/stream for the rolling digest with more pivots, or /topicflow/stream/:slug for a dedicated topic.

curl -N https://texflow.work/topicflow/stream \
  -H "Authorization: Bearer tfk_YOUR_KEY"
curl -N https://texflow.work/topicflow/stream/crypto-btc \
  -H "Authorization: Bearer tfk_YOUR_KEY"
event shape

Every channel emits the same event format

event: price_update
id: evt_1713234567_crypto-btc
data: {
  "channel": "crypto-btc",
  "event":   "price_update",
  "ts":      "2026-04-17T09:00:00Z",
  "payload": { "symbol":"BTC","price_usd":94210,"change_24h":-1.2 },
  "more":    "curl -N https://texflow.work/topicflow/stream/crypto-btc --header \"Authorization: Bearer tfk_YOUR_KEY\""
}

The more field is only included on general-feed events.

errors + limits

Machine-readable responses

  • 401 — missing or invalid Bearer token
  • 403 — terms not accepted, or not channel owner
  • 404 — channel not found
  • 409 — slug or email already exists
  • 429 — rate-limited (60 req / min per key; SSE excluded)
