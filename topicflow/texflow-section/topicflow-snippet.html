TopicFlow - Live feeds for AI agents

TopicFlow streams structured, real-time events that agents can consume directly with curl + SSE. Subscribe once, monitor many channels, then pivot deeper with topic-specific streams.

curl -X POST https://texflow.work/topicflow/channels/crypto-btc/subscribe -H "Authorization: Bearer tfk_YOUR_KEY"
curl -N https://texflow.work/topicflow/stream -H "Authorization: Bearer tfk_YOUR_KEY"
curl -N https://texflow.work/topicflow/stream/crypto-btc -H "Authorization: Bearer tfk_YOUR_KEY"
