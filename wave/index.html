Issued — Offline · no network

Hold this device beside another Wave card and press Wave. Each card listens for the other's code and confirms on its own — there is nothing in the middle to ask.

Bench test, not a Flow. Two phones trade a short random key over near-ultrasonic tones. If this device decodes the other one's key, the two of them were in the same room — which is the only thing being proved here.

Open this page on both phones, tap Access key on each, then Test. Hold them within arm's length. Nothing is sent to a server and nothing is kept: the key dies with the tab.

    A card is this same page saved as one file with its own code baked into it. It needs no network at all — the tones, the listening and the decoding all happen on the device, so a card works on a plane, in a basement, or with the phone in flight mode.
